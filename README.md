# XML-Reader

[![C#](https://img.shields.io/badge/C%23-100%25-green.svg)]()

Программа для чтения и обработки XML-файлов. Проект находится в стадии начальной разработки.

## Описание

**XML-Reader** — это консольное приложение, созданное на C# для загрузки, парсинга и отображения содержимого XML-документов. Основная цель проекта — предоставить простой и надежный инструмент для работы с данными в формате XML.

## Основные возможности

*   **Чтение XML-файлов**: Загрузка и парсинг XML-документов из файловой системы.
*   **Визуализация структуры**: Отображение иерархической структуры XML (элементы, атрибуты, значения).
*   **Обработка данных**: (Добавьте сюда конкретные функции, если они реализованы, например, поиск по узлам, валидация, преобразование в другие форматы).

> **Примечание**: Так как проект находится в активной разработке, функциональность может дополняться. Актуальный список возможностей всегда можно найти в коде и коммитах.

## Установка и запуск

### Требования
*   Visual Studio 2022 или более новая версия (рекомендуется)

### Инструкция
1.  **Клонировать репозиторий:**
    ```bash
    git clone https://github.com/yunnanke/xml-reader.git
    cd xml-reader
    ```
2.  **Открыть решение:** Дважды щелкните по файлу `xml-reader.slnx`, чтобы открыть проект в Visual Studio.
3.  **Собрать и запустить:** Нажмите `F5` или выберите `Запустить` в меню отладки.

Также можно собрать и запустить проект из командной строки:
```bash
dotnet build
dotnet run --project ./xml-reader/xml-reader.csproj
```
